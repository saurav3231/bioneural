## Where to Get Help

| Need | Where |
|---|---|
| Research / background questions | Repository Issues/Discussions |
| Defect or gap in the documentation | [Open an issue](https://github.com/saurav3231/bioneural/issues/new/choose) |
| Security vulnerabilities | [SECURITY.md](SECURITY.md) — report privately |
| General support | Open a discussion in the repository |

## Project Status

This is **SDLC Phase 1 — Theoretical Research & Architecture Study**. There is **no executable
software yet**; the repository contains the formal research baseline. Please set expectations
accordingly and consult the roadmap before filing feature requests.

## Community Standards

All interactions are governed by our [Code of Conduct](CODE_OF_CONDUCT.md). Be kind, be scientific,
be constructive.
